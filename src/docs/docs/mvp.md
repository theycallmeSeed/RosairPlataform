# MVP Scope

## Objetivo

Validar a operação do marketplace antes do desenvolvimento completo da plataforma.

O MVP não pretende processar pagamentos reais nem gerir operações reais.

O objetivo é demonstrar fluxos de negócio.

---

# Perfis

## Comprador

* Pesquisar produtos
* Solicitar cotação
* Acompanhar pedidos

## Agente

* Publicar produtos
* Gerir catálogo
* Receber pedidos

## Administrador

* Aprovar agentes
* Gerir produtos
* Monitorizar pedidos
* Visualizar analytics
