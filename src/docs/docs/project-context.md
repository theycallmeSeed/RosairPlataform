# Roseair Marketplace - Project Context

## Project Vision

Roseair Marketplace is a B2B regional trade platform connecting:

* Buyers
* Importers
* Chinese Agents
* Suppliers
* Logistics Operators
* Warehouses
* Customs Operations

The platform's objective is to formalize and scale trade currently performed through WhatsApp groups and informal channels.

Roseair controls and monetizes:

* Logistics
* Freight
* Warehousing
* Customs Clearance
* Trade Operations

The marketplace acts as the digital entry point for these services.

# User Roles

## Buyer

Can:

* Search products
* Request quotations
* Track orders
* Manage profile

Cannot:

* Access analytics
* Manage products

---

## Agent

Can:

* Publish products
* Manage catalog
* Receive quote requests
* Manage offers

Cannot:

* Access executive analytics

---

## Admin (Roseair)

Can:

* Manage users
* Manage products
* Approve agents
* Manage logistics
* Manage customs
* Manage warehouses
* View analytics

Analytics is ADMIN ONLY.
